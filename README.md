# 🎮 PatoghGame (پاتوق گیم) — GTA VI Vice City Edition

پلتفرم جامع میزبانی سرورهای رایگان بازی و برگزاری تورنمنت‌های هفتگی با طراحی الهام‌گرفته از خیابان‌های **GTA VI / Vice City**.

🔗 **دموی زنده روی پاستا (Paasta Cloud):** [https://patoghgame.neda1.paasta.app](https://patoghgame.neda1.paasta.app)

---

## ✨ ویژگی‌ها و المان‌های شهری
- **خیابان‌های وایس‌سیتی و رادار GPS:** هدر و بخش Hero با حال و هوای غروب لئونیدا، پلاک `PATOGH-6` و رادار زنده.
- **کلوب‌ها و مناطق شهر (سرورهای بازی):** نمایش سرورهای فعال (Minecraft، CS2 و ...) به عنوان مکان‌های معروف شهر مانند کلوب مالیبو و اسکله وایس‌پورت با امکان کپی سریع آی‌پی.
- **بیلبورد بزرگ اتوبان (راهنمای اتصال):** تابلوی غول‌پیکر نئونی کنار جاده با نورافکن، شامل راهنمای ۳ مرحله‌ای ورود برای کلاینت‌های کرک و اورجینال.
- **قراردادهای خیابانی (رویدادها و تورنمنت‌ها):** مسابقات با جوایز نقدی و فرم ثبت‌نام آنلاین رایگان.
- **لیست تحت تعقیب‌ترین‌ها (Most Wanted):** جدول افتخارات و برترین بازیکنان شهر.
- **باجه تلفن همگانی (Community Payphone):** لینک‌های مستقیم ارتباط با دیسکورد و تلگرام.
- **اتاق کنترل دوربین‌ها (`/admin`):** پنل مدیریت با استایل CCTV جهت تغییر وضعیت سرورها، انتشار پیام در رادیو `VICE FM 98.5`، ساخت یا ابطال قراردادهای مسابقه و مشاهده لیست ثبت‌نام‌ها.

## 🚀 اجرا و استقرار

### ۱. اجرای محلی با Docker
```bash
docker build -t patoghgame .
docker run -p 3000:3000 -e ADMIN_KEY=patogh2026 patoghgame
```

### ۲. استقرار روی پاستا (Paasta)
این پروژه بهینه شده است تا حتی روی **حداقل پلن پاستا (Basic - 256MB RAM / 0.25 CPU)** با پورت `3000` اجرا شود.

### ۳. سرورهای بازی
تنظیمات داکر سرور ماینکرفت و تانل `Playit.gg` در پوشه `gameservers/minecraft/docker-compose.yml` نگهداری می‌شود.
